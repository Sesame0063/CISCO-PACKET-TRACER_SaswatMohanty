# Cisco Packet Tracer – Computer Networks Lab

A collection of all the **Cisco Packet Tracer (`.pkt`) simulation files** created for the **Computer Networks (CN) Lab**. Each file is a self-contained network scenario that can be opened, simulated, and modified in Cisco Packet Tracer.

---

## Repository Contents

| # | File | Topic | What it Demonstrates |
|---|---|---|---|
| 1 | `1.Simple Network and Topology.pkt` | Basic Network & Topology | Connecting PCs through switches/hubs, basic IP addressing, and testing connectivity using `ping`. |
| 2 | `2.Router networks.pkt` | Routers | Connecting multiple networks via routers, configuring router interfaces, and inter-network communication. |
| 3 | `3.DHCP.pkt` | DHCP | Automatic IP address allocation to hosts using a DHCP server/pool. |
| 4 | `4.Different servers.pkt` | Network Servers | Setting up and accessing services such as DNS, HTTP/Web, and FTP on server devices. |
| 5 | `5.Email Service.pkt` | Email Service | Configuring a mail server (SMTP/POP3) and sending/receiving emails between clients. |
| 6 | `6.Static routing and VLAN.pkt` | Static Routing & VLANs | Configuring manual routes between networks and segmenting a LAN into VLANs. |

---

## Requirements

- **Cisco Packet Tracer** (any recent version; 8.x recommended).
- A free Cisco Networking Academy account to download Packet Tracer: https://www.netacad.com/

---

## How to Use

1. Clone or download this repository.
2. Open **Cisco Packet Tracer**.
3. Go to **File → Open** and select any `.pkt` file.
4. Switch to **Simulation Mode** to watch packets move through the network.
5. Alternatively, use **PC → Command Prompt** to run commands such as `ping` and `ipconfig`.

---

## Lab Overview

### 1. Simple Network and Topology
Building a small LAN, connecting end devices through a switch, configuring IP addresses, and verifying connectivity between hosts.

### 2. Router Networks
Connecting separate networks through routers, configuring router interfaces, and understanding default gateways.

### 3. DHCP
Demonstrating how a DHCP server automatically assigns IP configuration (IP address, subnet mask, gateway, and DNS) to hosts.

### 4. Different Servers
Exploring multiple server roles in a network and allowing clients to access services hosted on server devices.

### 5. Email Service
Configuring an email server and client accounts to demonstrate how emails are sent and received within a network.

### 6. Static Routing and VLAN
Configuring static routes so routers can communicate with remote networks and creating VLANs to logically separate network traffic on switches.
